# 할 일 관리 앱 PRD

## 1. why - 목적

* 단기 할 일과 장기 목표(연간)를 하나의 구조로 연결해 실행력을 높인다.
* 할 일 완료가 주간 계획, 나아가 연간 목표 달성으로 이어지는 것을 시각적으로 확인시킨다.
* 상태 관리와 드래그 앤 드롭으로 할 일 처리 흐름을 직관적으로 만든다.

## 2. who - 타깃 사용자

* 연간 목표를 세우지만 일상 실행과 연결하지 못해 흐지부지되는 개인 사용자
* 주간 단위로 계획을 세우고 진행률을 추적하고 싶은 자기관리형 사용자
* 칸반 보드 방식(todo/doing/done)의 직관적 UI를 선호하는 사용자

## 3. User flow

1. 사용자가 1년 목표를 등록한다.
2. 1년 목표 하위에 주간 계획을 등록/연결한다.
3. 주간 계획 하위에 할 일(daily task)을 생성한다.
4. 사용자가 할 일을 CRUD로 관리한다.
5. 사용자가 할 일 카드를 드래그 앤 드롭으로 todo → doing → done 상태로 이동한다.
6. done 처리된 할 일 비율에 따라 상위 주간 계획의 진행률이 자동 갱신된다.
7. 주간 진행률 누적을 통해 1년 목표 화면에서 전체 진행 상황을 확인한다.

## 4. 기능 요구 사항

### 할 일 CRUD
* 할 일 생성/조회/수정/삭제
* 제목, 설명, 기한, 상위 주간 계획 연결 필드 포함

### 상태 관리
* 상태값: todo / doing / done
* 상태 변경 시 타임스탬프 기록(진행률 계산용)

### 드래그 앤 드롭
* 보드 뷰에서 카드 드래그로 상태 컬럼 간 이동
* 드롭 시 상태 자동 업데이트 및 진행률 재계산 트리거

### 기간 구조
* 일일: 할 일(Task) 단위
* 주간: 주간 계획(Weekly Plan) 단위, 여러 할 일을 포함
* 연간: 1년 목표(Yearly Goal) 단위, 여러 주간 계획을 포함

### 구조 연결
* 할 일 → 주간 계획 → 1년 목표의 상하위 참조 관계 필수
* 상위 목표 미지정 할 일도 생성 가능(단, 진행률 집계에서 제외)

### 주간 진행률 자동 반영
* 주간 계획 진행률 = (done 할 일 수 / 전체 할 일 수) × 100
* 할 일 상태 변경 시 실시간 재계산
* 연간 목표 화면에서 하위 주간 계획들의 평균 진행률 표시

## P0 - 핵심 기능

* 할 일 CRUD
* 상태 관리(todo/doing/done)
* 드래그 앤 드롭 상태 변경
* 일일/주간/연간 계층 구조 생성
* 할 일 - 주간 계획 - 연간 목표 연결
* 주간 진행률 자동 계산 및 반영
